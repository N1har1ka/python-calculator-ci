Python Calculator CI

Task 1: Set Up a GitHub Repository

  1. Create a new GitHub repository named python-calculator-ci.
  2. Clone the repository to your local machine:
git clone https://github.com/your-username/python-calculator-ci.git
cd python-calculator-ci

Inside the project folder, create the following structure:

python-calculator-ci/
│── .github/workflows/ci.yml   <- GitHub Actions workflow
│── calculator.py               <- Python calculator
│── requirements.txt            <- Dependencies
│── tests/
│   ├── __init__.py             <- Marks folder as a package
│   └── test_calculator.py      <- Automated test file
│── README.md                   <- Project documentation

Task 2: Implement the Python Code

  1. Create calculator.py and add the following code:
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b
